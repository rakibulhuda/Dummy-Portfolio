# Dummy Portfolio

A practice project where I turn a Figma design into a working personal portfolio website.

## About This Project

This is a **dummy portfolio** I built to convert what I've learned into professional practice. Translating a Figma design into code is a core part of a web developer's job, so this project is my way of practicing that workflow: reading a design, measuring spacing and typography, and recreating it as closely as possible in the browser.

It's not a live portfolio. It's a learning exercise focused on building real-world skills.

## Design File

The original Figma design is included in this repo so anyone can look at it and compare it with the final result:

📁 [`design/portfolio-design.fig`](./design/portfolio-design.fig)

Note: GitHub can't preview `.fig` files. Download the file and import it into [Figma](https://www.figma.com) (File → Import) to view it.

## What I'm Practicing

- Converting Figma designs to pixel-accurate code
- Semantic HTML and clean CSS structure
- Responsive layouts (mobile, tablet, desktop)
- Consistent spacing, typography, and color usage
- Organizing a project like a professional would
